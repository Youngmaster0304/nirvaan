Current Problems (from Railway Board Review)

  • Blocks treated as "favors" - not granted as entitlement
  • No written record of block refusals - everything via phone calls
  • Rolling Block Programme not honored by Operating department
  • Maintenance corridors in Working Time Table violated
  • Same time slot sold twice - for trains and corridors
  • Safety incidents (Kanchanjunga, Khatauli) linked to delayed maintenance

  • Transparent audit trail - every block demand and refusal recorded
  • Corridor availability checked against real train timetable data
  • Critical defects auto-prioritized - safety-first approach
  • Weekly + monthly rolling plans generated by AI optimization

Active Token Locks

Deadlock Prevention Rules

  • Only ONE direction can hold a token per single-line section at a time
  • UP and DOWN tokens are mutually exclusive
  • Token must be released before opposing direction can acquire
  • System prevents head-on deadlock by blocking conflicting lock requests
  • Real-time token status visible to Section Controller

HOER Crew Compliance

Crew Duty Status

HOER Rules (Hours of Employment Regulation)

  • Max continuous duty: 10 hours per shift
  • Minimum rest period: 8 hours between shifts
  • Non-linear penalty: each extra hour exponentially increases risk
  • Automatic reassignment when crew approaches duty limit
  • Controller alerted 1 hour before HOER expiry
